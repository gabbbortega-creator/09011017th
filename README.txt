EIYHANA WEBSITE

Pages: index.html, shots.html, smile.html, october.html, songs.html, letters.html

PHOTOS
Put photos in photos/shots, photos/smile, photos/october. Then edit the galleries at the top of script.js.
Put a background image at photos/background.jpg if desired.

MUSIC
Put audio files in songs/. Edit playlist at the top of script.js. Use forward slashes in paths, e.g. songs/BawatDaan.mp3.

LETTER
Put your PDF at letters/my-letter.pdf.

Run with VS Code Live Server.
